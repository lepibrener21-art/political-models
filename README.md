# Political Models

A structured catalogue of political and governance models, old and new, evaluated for how well they could serve people today and in the future.

## Question this repo explores

Systems can be placed on scales: how much **personal freedom** people keep, how much **real power** they have over collective decisions, and how well they are **protected**. Which models, existing or proposed, score well on all of them at once, and under what conditions?

## Layout

```
INDEX.md            One line per model with scores. Start here.
AGENTS.md           Rules for AI assistants working in this repo.
framework/
  axes.md           The scoring axes and 1–5 rubric.
  baselines.md      Reference systems (monarchy, representative democracy…).
  template.md       Copy this to add a model.
models/<slug>.md    One card per model, fixed headings.
ideas/inbox.md      Raw ideas not yet developed into cards.
sources.md          Shared bibliography; cards cite by key, e.g. [ostrom1990].
```

## Workflow

1. Drop a rough idea into `ideas/inbox.md`.
2. When it's worth developing, copy `framework/template.md` to `models/<slug>.md`.
3. Score it against `framework/axes.md` and add a row to `INDEX.md`.
4. Add any new references to `sources.md` and cite them by key.

## Status of the scores

Scores are initial, subjective estimates meant to make comparisons concrete. Every one is open to challenge; disagreements belong in the card's **Open questions** section.
